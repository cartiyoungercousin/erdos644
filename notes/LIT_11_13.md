# Literature check: 11/13 repo, trureturing #9792, EFKT92

## 1. skyvegetable666/erdos-644-11-over-13 (https://github.com/skyvegetable666/erdos-644-11-over-13)
Claim: tau <= 11k/13 + 8 for k>=20 (PROOF.md). Self-described "internally checked, not mechanized"; AI-assisted; 3/4 stated open.

**Anchor choice (PROOF.md s5).** Among good triples, take the one whose DEcreasingly sorted pair-profile (u,v,w) is
lexicographically least (u>=v>=w). So the potential is lexicographic (largest cell, then middle, then smallest), not 4*s1+s2.
Minimality is used only as the non-strict conditions (7): L>=u; L=u => B>=v; L=u,B=v => S>=w.
Also attained-extrema trick: x = largest *small* pair cell (<= c-1/2), Y = smallest *large* one; every attained pair is <=x or >=Y (s4).

**Ties / equal-potential responses.** Not eliminated by contradiction. Responses (j,a,h+b), (g,a,h+d) are just known to satisfy (7) (non-strict),
plus (9): every actual pair t has t>=u or 2u+t<2-c; plus (8) 2u+v<2-c (query k-U+1 pts from each edge of the min pair). The ties enter
as extra linear constraints on the response traces; the contradiction comes from an LP/RUP certificate over 4 fixed queries
(U0, UhD, U1D, V1D: anchor order (u,v,w) or (v,u,w), theta in {0,1/2,1}, optional "target level" l in {u,v} which forces h+d<l).
So the equal-level-set move is absorbed by case-splitting inside the certificate, not by a clean minimality argument.
Our minimal-potential idea IS present in substance (lex-min is a refinement of any scalar potential), plus much more (9),(10).

**Reduction shape.** (s2) covering principle: r anchors with empty intersection + (7-r) blocks of size <=T covering every candidate pair => tau<=T.
Good triple: candidate-pair graph on 6 regions (3 pair cells P_i, 3 singletons S_i): edges P-P, P_i-S_i. Four-query response edge E adds
traces h,a,b,d (caps (11), strict via +1 extra point per residual region; query size <= ck+8). With response: 8-class graph, edges 01,02,03,04,15,26,37.
Supports = lists of block masks (3 or 4 blocks); fractional min max-load = LP dual (12), vertices from {-1,0,1}-hyperplanes (10 dirs for 3 blocks, 101 for 4);
rounding costs <=3 extra points. Certified by computer (exact rationals + RUP): 27 formula groups, 919 arithmetic clauses, 63 RUP steps.
NOT certified by computer (written argument): all query/response necessity statements, supports being valid covers (checker does test mask-intersection), rounding.
Independent integer lemmas: tau <= X + ceil(k/2) for ARBITRARY triples (docs/maximum_pair_lemma.md); tau <= (3k-P)/2+3 (symmetric-difference 4-block cover, s3);
(6): 3-b-d-3Y+2x-s > c (two-large-one-small).

**Barrier below 11/13.** No explicit stated barrier. Only: "does not resolve the conjectured 3/4". 11/13 is just the point where the finite LP becomes infeasible
with these 4 queries. Not extracted from the repo: which constraint is tight.

## 2. the-omega-institute/trureturing #9792 (https://github.com/the-omega-institute/trureturing/issues/9792)
Open status, no comments. Body (single long post) states NO claim that anchor/covering-principle architecture cannot reach 3/4. Statements found:
- Limitation of FKW99 Lemma 1 "two blocker architectures": |S_7| >= 3(k-T)+x, so fitting blocks within T needs x <= 4T-3k;
  with x the largest pair intersection, T=(3/4+o(1))k forces all three intersections o(k). "This only limits those two architectures."
  (Sketch: count points forced into a seventh set; no proof given in the issue.)
- Conditional composition bound: resistant triples in both components => added blocks cover with <=3 min(d1,d2) blocks.
- Cartesian-product composition gives only (k1+k2)/5+2 cover; Fano/coding route (Furedi 1981; n<9k/5, 7d>3(4n-7k)); counting + Frankl-Wilson
  restrictions leave nonempty parameter region (7b/3<=a<=9/5 etc.). Recorded: nothing resolved. Related issue #9804 is Erdos 757 (unrelated).
Our x>=y>=z / "max pair cell" obstacle is consistent with their remark but no stronger general no-go is stated.
