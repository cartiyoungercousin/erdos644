## 1. Definitions used

Units k = 1, t = 3/4 + ε, c = N − 1, ω = N − 1 − t = δ − ε, δ = N − 7/4. The window above the strip is δ > 5ε
(N > 5t − 2) and N < 3 − t. A static r-certificate is r members K_1..K_r and 7 − r requests L_{r+1}..L_7 with
|L_j| <= t such that the co-types J_x = {i : x ∈ K_i or x ∈ L_i} are nonempty and pairwise intersecting. Replacing
each L_j by a member containing it only enlarges co-types, so a T-covering family that contains K_1..K_r has a good
seven (1.1). I checked this monotonicity, and it is correct.
G = {K : |K| = c, x_0 ∉ K, Y ⊆ K} with x_0 ∉ Y and |Y| = y.

## 2. Theorem 96.1, step by step [proved by hand]

**Step 1: every co-type has size >= 3.**
- J_{x_0} ⊆ {r+1..7}, since x_0 lies in no member. It is nonempty, so r <= 6.
- Every co-type meets J_{x_0}, so none lies inside [r].
- If some point has co-type {a}, every co-type contains a, so the set a equals V. That is impossible, since
  c < N and t < N.
- If some point has co-type {a, b}, every point lies in set a or set b, so their union is V.
  - Member and request: c + t >= N, i.e. t >= 1. False.
  - Two requests: 2t >= N. False, since N > 5t − 2 > 2t when t > 2/3.
  - Two members: excluded, because the co-type would lie inside [r].
- The argument is pointwise. It applies to x_0 as well, and it does **not** use N < 2. The claim "also for N >= 2"
  is correct: the case that needs N < 2 elsewhere (two members covering V, 2c >= N) is excluded here by x_0.

**Step 2: waste budget.**
- Σ_x |J_x| = Σ_i |K_i| + Σ_j |L_j| <= rc + (7 − r)t.
- Then rc + (7 − r)t − 3N = (r − 3)N − r + (7 − r)t.
- Substituting N = δ + 7/4 and t = 3/4 + ε gives (r − 3)δ + (7 − r)ε + [7r/4 − 21/4 − r + 21/4 − 3r/4]
  = (r − 3)δ + (7 − r)ε = S_r. The bracket is 0. Checked.
- Since every |J_x| − 3 >= 0 (Step 1), any partial waste is <= S_r.

**Step 3: cases.**

| r | argument | needs | holds |
|---|---|---|---|
| 0, 1, 2 | S_r = −3δ + 7ε, −2δ + 6ε, −δ + 5ε < 0 <= waste | δ > 5ε (r = 2 is the binding case) | yes |
| 3 | J_{x_0} ⊆ {4..7}. Y-points have J ⊇ {1,2,3} plus a request, so |J| >= 4 and waste >= y | y > S_3 = 4ε; (δ+3ε)/2 > 4ε ⟺ δ > 5ε | yes |
| 4 | J_{x_0} = {5,6,7}. Y-points have J ⊇ [4] plus one of 5, 6, 7, so |J| >= 5 and waste >= 2y | 2y > S_4 = δ + 3ε | yes |
| 5, 6, 7 | |J_{x_0}| <= 7 − r <= 2 < 3 | none | yes |

So the r = 4 case is the binding one, and it gives exactly the hypothesis y > (δ + 3ε)/2. The r = 3 case needs
only y > 4ε. Finite k: with |Y| > ((δ + 3ε)/2)k points the same counts hold in integers. Passes.

**Independent MILP** (`cert_threshold.py`, float). For each r it maximises the core mass y over all intersecting
co-type families on [7], with an x_0-cell of mass 0.002 whose co-type avoids [r]. I tested 3 values of ε (0.0021,
0.01, 0.03) and 4 to 6 values of N each, across the window.
- r ∈ {0, 1, 2, 5, 6, 7}: infeasible in every case.
- r = 3: y* = 4ε exactly.
- r = 4: y* = (δ + 3ε)/2 to 4 decimals (0.2032 against 0.2031 at one point, an x_0-cell effect).

This reproduces the hand threshold and its sharpness, and it shows the r = 3 bound 4ε is also sharp.

## 3. Density comparison, re-run [computed float]

ρ_G = N h(c/N) − (N − y) h((c − y)/(N − y)) at y = (δ + 3ε)/2, and γ = (N − t) h(ω/(N − t)). This γ is the floor
for T-covering families: C(n,c)·C(c,T) = C(n,T)·C(n−T, c−T), so |𝒞|/C(n,c) >= 1/C(n−T, c−T). I checked the
identity. The formula |G|/C(n,c) = (1 − c/n)·C(n−1−y, c−y)/C(n−1, c) is also correct. I used a grid of 4000
values of N per ε.

| ε | max ρ/γ (at N) | CORE table |
|---|---|---|
| 1e-5 | 0.1669 (top) | — |
| 1e-4 | 0.1670 (top) | 0.167 |
| 1e-3 | 0.1681 (top) | 0.168 |
| 0.01 | **0.1945 (N ↓ 1.800)** | 0.183 |
| 0.03 | 0.2469 (bottom) | — |
| 0.05 | 0.2770 (bottom) | 0.275 |
| 0.08 | 0.3070 | (outside the tested range) |

- At N = 2 as ε → 0: ρ = 0.0908 and γ = 0.6255, as in CORE.
- γ − ρ_G > 0 everywhere on the grid.
- At finite k = 400 the exact log-binomials, including the x_0 factor, give ratios 0.170–0.179 (ε = 0.01) and
  0.247–0.267 (ε = 0.05).
- A rigorous route: the elementary bound ρ_G <= y ln(N/(c − y)) holds because each factor (c−i)/(n−i) is
  >= (c−Y)/n. That bound is itself < 0.34γ on the whole tested grid. Turning "ρ_G < γ" into a proof only needs
  this two-variable elementary inequality to be shown, for example by interval arithmetic. That has not been done.

## 4. Does 96.1 support "no forbidden-pattern rate can beat γ"?

**What follows, with the missing line written out.** Let 𝒫 be any class of static certificates. Suppose a
theorem says: every family of c-subsets of V with density >= e^{−δ_𝒫 k} contains a member of 𝒫, for all large k.
- G is 𝒫-free (96.1), so a valid theorem must have δ_𝒫 <= ρ_G + o(1).
- To apply the theorem to every T-covering family, one needs e^{−γk} >= e^{−δ_𝒫 k}, i.e. δ_𝒫 >= γ. This
  threshold cannot be lowered: covering designs (Rödl) have density e^{−γk + o(k)}.
- Since ρ_G < γ [computed float], no such theorem exists, whether explicit or ineffective.

So the "separate quantitative derivation" the reviewer asked for is this one line plus the inequality ρ_G < γ.
96.1 together with the rate table does support it, and with room: δ_𝒫 <= 0.28γ.

**What does NOT follow; the slogan overreaches here.**
1. It concerns pure-density hypotheses only. G fails T-covering exactly at the t-sets through x_0 (§98.3).
   Theorems that also assume point coverage, link density (LD_a), degree regularity, or T-covering itself are
   outside 96.1. §98.3 treats point coverage only by a float search, and leaves the sliver N < ~1.771 open.
2. It concerns static certificates only. A "forbidden pattern" whose presence certifies only together with
   adaptive requests (requests chosen after replies) is not covered. §99 says so ("Not covered"), but 96.2's
   wording ("any other static certificate") is correct only with "static".
3. "Rate" means the exponent of a single global density threshold. Supersaturation-plus-structure arguments that
   count copies and then use T-covering locally are not density-only and are not excluded.
4. ρ_G < γ is a float grid statement for ε <= 0.05. It is not a theorem. The claim "ratio → 0 near the bottom"
   is heuristic asymptotics, consistent with the grid.

**Suggested rewording of 96.2:** "For every ε <= 0.05 and N in the window [computed float], and every class 𝒫 of
static certificates, any theorem 'density >= e^{−δk} among c-subsets of V forces 𝒫' has δ <= ρ_G(N, ε) <= 0.28γ.
In particular no density-only argument reaches γ. Arguments that use coverage of points, links or t-sets beyond
the global density are not addressed."

## 5. Links paragraph

Every link of a T-covering family has the same floor. 𝒞_A is (T − a)-covering by (c − a)-sets on n − a points,
so its floor is 1/C(n − T, c − T), the same γ. G_A ⊆ link has relative cost that of Y′ alone, and 96.1 applies
with Y = A ∪ Y′. Passes. The same caveats 1–3 apply.
