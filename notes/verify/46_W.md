# Verification of CORE §46 and §47 (Theorem W)

Code (independent of compute/core8): compute/verify/vw.py (W), compute/verify/v46.py (§46). Both apply the rule verbatim to real sets,
then check every pair of the seven replies via co-types (I_x & I_y != 0 for all x,y).

## Verdicts
**§46 (ordered frozen anti-plan has a good seven): PASS** (first order by hand; finite k exact for even k).
- Hand proof re-derived: L-pencil (kernel >= 2*omega <=> omega <= T-k/2, exact), H-pencil (needs o - omega <= 3(omega-1) in integers, i.e. o <= 4*omega-3; the stated
  "o < 4*omega" is not enough at finite k, but the case split survives: omega > T-k/2 and o >= 4*omega-2 gives o > T = c-omega, since 3T >= 9k/4 > 2k-2, contradicting |U| >= 2*omega).
- v46.py: 2056 (k,T,n,o) configurations, k in {8,10,12,14,16,18,20,22,24,40}, T = ceil(3k/4)..+2, n up to 2.3k, all o >= max(2*omega, n-2k):
  1606/1606 in-hypothesis cases have a good seven (H or L branch), 450 outside hypothesis (o<2*omega, |g|<0 or omega<1), 0 failures.
  Kernel filler/head choices adversarial (L-branch takes the LAST omega points of O).

**Theorem W (window of <= T-k/2 points, any classes/orders): PASS** for k even; exact bound |W| <= T - ceil(k/2).
- Proof checked step by step: window in all three requests fixes class r; Z = first omega of V\W in order r; every point outside W u Z follows Z, so reply = S_i u Z = line;
  heads overlapping W are harmless (W points are requested, hence skipped); kernel room n-3k/2-omega = T-k/2 exact; transversals (3k/4 <= T) need only a superset, so any reply works.
- vw.py: 41,940 runs, k = 4..30 and 40, T = ceil(3k/4), +1, +3, five n per T, |W| in {0,1,wmax/2,wmax}, adversaries: random tables (2/8/64 classes), parity with every order headed by W,
  hash selector with orders tied to window distance, interleaved heads, majority; kernel filler random / earliest-in-order / latest; transversal replies by rule or arbitrary (evil). 0 failures.

## GAPS / minor errors (none changes a verdict)
1. 47.2 "exact for 4 | k": for odd k and T = ceil(3k/4) with k = 1 mod 4 (k=5,9,13,...), the pencil frame (kernel n-ceil(3k/2), petals (k+1)/2,(k+1)/2,(k-1)/2) has NO class split with all four transversals <= T (36/36 'noplan' cases in vw.py);
   other kernel sizes lose room. k = 2 mod 4 works but needs the right Fano coset/class sizes (3*ceil(k/4) > T otherwise). Statement is fine as written (4|k), but "finite-k exact" claims for 4 does not divide k are not covered.
2. Odd k: the three requests have different sizes (T, T, T-1), so the selector must not read |S|; hypothesis "depends only on S cap W" covers this, but a size-dependent selector is outside W.
3. 47.2 threshold corollary: leftover points of E (|E| > 3*theta-2x) must be placed; this is fine only for UPWARD thresholds, and needs Z cap E = empty (stated as "starts outside E"). Downward thresholds are handled separately; ok.
4. 46.1: the rule is only defined for |S| = T (dump omega). For transversal requests (|S| < T) the dump exceeds the chosen cell (o or 2(c-o) may be < d); my run hit the fallback there. Harmless since transversal replies are arbitrary, but "well defined on the requests used" should say pencil requests only.
5. 46.2 H-pencil: petals must hold the O points (o - omega <= 3(omega-1) and per-petal capacity k/2); kernel needs |U|+|g| >= n-3k/2-omega. Not stated; true in the scanned region (also verified in v46.py: no 'notapplicable' remained).
6. W covers stateless (history-independent) greedy rules only; fine as stated.
7. 46.5 "extends verbatim to any rule 'first omega of a cell chosen by profile'" is a corollary of W only when the profile is a window/threshold; not written.
