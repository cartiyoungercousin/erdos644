Notation as in PROGRAMME_2.md. H is k-uniform on V, n = |V| = (7/4+δ)k, τ = τ(H) ≥ T+1, T = ⌈(3/4+ε)k⌉ (or any
T < τ). Then H is **T-covering**: every set of size ≥ n − T contains a member. Put r = n − T − k, so r ≈ (δ−ε)k.
A **hole** is a set containing no member. A **pencil triple** is three members x1, x2, x3 with x1∩x2∩x3 = ∅.
P(H) is the least wt(x1+x2+x3) over pencil triples.

## 0. Verdict
- **Target not proved.** I do not have a gluing argument giving "all but o(|H|) members in one coset". §6 states the
  exact remaining gap (INV-P).
- **The 7-term route (Lemma 5 stability plus BLR gluing) is the wrong tool** [dead as stated, §3]. The local stability
  step is easy and sharp (§2). But "no Fano plane" is a condition of true complexity 2 over F₂: quadratic level sets
  avoid Fano planes. So no linear-Fourier or BLR argument can get a coset from the 7-term condition alone.
- **The right mechanism is 3-term: robust pencil-freeness** [proved by hand, §4].
  - A seven-free T-covering family has P(H) ≥ 4T − 3k − 5 ≈ 4εk.
  - Covering gives P(H) ≤ 2r + 1.
  - Together: τ ≤ (2n + k)/6 + 2 for every k-uniform (7,2) family, i.e. **δ ≥ 3ε**. This is the same constraint as
    Theorem NC with W = V, obtained independently, which is a useful cross-check. C1 does not depend on NC.
  - Robust pencil-freeness is a Schur-triple condition (x3 ≈ x1 + x2 is forbidden), so it is linear-complexity.
- **Two-block families satisfy (G) with o(k) = 3** [proved by hand + computed, §5]. So C holds vacuously for them.
  Below that threshold, seven-free two-block families far from every coset exist: k = 10, n = 18, τ = 8 = 3k/4 + 1/2,
  with only 86% of members in the best half-space [computed exact]. **Any proof of C must use εk → ∞.** No argument with
  O(1) slack can give near-coset structure.

## 1. F₂ form of Fano-type sevens [proved by hand]
Index lines by u ∈ F₂³∖0, points by q ∈ F₂³∖0, with q ∈ ℓ_u iff u·q = 0. A colouring χ gives a_x = χ(x) ∈ F₂³.
Then R_{ℓ_u} = {x : u·a_x = 1} =: φ(u), and φ: F₂³ → F₂^V is linear. Conversely, every linear φ arises this way,
with a_x = 0 allowed; a point coloured 0 lies in no R, which only shrinks the R's.
- **C0.** Let 𝒰 be the up-set generated by H. H has a Fano-type good seven ⇔ some 3-dimensional subspace W ≤ F₂^V has
  W∖{0} ⊆ 𝒰. Equivalently, **H is seven-free ⇔ holes block every Fano plane of F₂^V.**
- So C is a Bose–Burton stability problem in the thin shell. In dense F₂^m, the largest Fano-free sets are complements
  of codimension-2 subspaces, density 3/4 (Bose–Burton).
  - FKW is exactly this: its holes in the k-slice are U ∩ slice, where U = {even on X, even on Y} has codimension 2.
  - The other two cosets of U have odd weight, so they are absent at even k.

## 2. Stability of Lemma 5 (the local step) [proved by hand]
Take a Fano-type seven B_u ⊆ R_{ℓ_u}, and let J_x = {u : x ∈ B_u}. By the colouring, J_x ⊆ A_q := {u : u·q = 1}, the
4 lines missing q = χ(x). The linear patterns are exactly ∅ and the A_q.

| j_x | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| cost j(4−j) = #pencils with odd parity at x | 0 | 3 | 4 | 3 | 0 |
| d_x = distance of J_x to the nearest linear pattern | 0 | 1 | 2 | 1 | 0 |

(For j = 2 the nearest are ∅ and any A_q with q off both lines; for j = 3 it is the A_q containing J_x.)
- **Lemma CL.** Let S = Σ_p wt(s_p). Choose a′_x ∈ F₂³ realising d_x and set ψ(u) = {x : u·a′_x = 1}, which is linear in u.
  Then
  Σ_u |B_u Δ ψ(u)| = Σ_x d_x ≤ S/2 ≤ 6δk.
  - Equality S = 2Σd holds iff no point has odd j.
  - S = 0 gives B_u = ψ(u), the zero-slack subspace statement.
- *Coset reading.* If H ⊆ a + C, every s_p lies in a + C, so S ≥ 7ρ. With S ≤ 12δk this is Corollary 7.
- *Near-sevens.* For a colouring with six lines realised, the same table restricted to the 4 pencils avoiding the
  missing line gives Σ_x d′_x ≤ S′/2 for the 6-line pattern.
- Local stability therefore costs nothing. All the difficulty is in the gluing.

## 3. Why 7-term gluing cannot work [proved by hand; the route is dead as stated]
- **Claim.** Let q: F₂^m → F₂ be any polynomial of degree ≤ 2 with q(0) = 0. Then {q = 1} contains W∖0 for no
  3-dimensional W.
  *Proof.* On W ≅ F₂³, q is still of degree ≤ 2. But 1_{W∖0} = 1 − Π(1 − x_i) has degree 3.
- For a non-degenerate quadratic form, {q = 1} has density about 1/2 and every non-trivial Fourier coefficient is
  ≤ 2^{−m/2}.
- So "no Fano plane" (a 7-term condition, Cauchy–Schwarz complexity 2) does not force linear structure. Any BLR or
  linear-Fourier gluing would also "prove" that these quadratic sets are near hyperplanes, which is false. A 7-term
  argument needs a U³ inverse theorem, and its output would be quadratic, not a coset.
- In the shell the quadratic sets themselves are harmless. Once 4n ≥ 7k + 7, a Fano plane can be chosen with every
  weight ≥ k + 1, and a generic quadratic level set is then 1-dense in 𝒰 [heuristic]. The lesson is only about the
  method: extract a 3-term condition first. §4 does this.

## 4. The 3-term mechanism [proved by hand]
**Lemma P1 (pencil ⇒ seven).** Let H be T-covering with sets of size ≤ k. Let x1, x2, x3 be a pencil triple with
w = wt(x1+x2+x3) ≤ 4T − 3k − 6. Then H has a Fano-type good seven.
*Proof.*
- Write E_i for the points only in x_i, D_ij for the points in x_i ∩ x_j, and Z = V∖∪x_i. The three lines through
  p0 are ℓ_i = {p0} ∪ Q_i, with Q_i = {q_i, q_i′}.
- Colour Z → p0, D_ij → Q_k, and E_i → Q_{i+1}. Split each Q_i-class evenly between q_i and q_i′. Then x_i ⊆ R_{ℓ_i}.
- Each of the other four lines takes one point from each Q_i, and each point of Q_i lies on two of them. So every such
  R has size ≥ |Z| + (|∪x_i| − 3)/2 = n − |∪x_i|/2 − 3/2.
- Since |∪x_i| ≤ (3k + w)/2, this is ≥ n − T, so R contains a member.
- Lemma 2 finishes. Repeated members are harmless.
Tested end to end inside two-block families (§5): 600/600 explicit sevens, brute-force checked to have no 2-point
transversal [computed exact].

**Lemma 8′ (Lemma 8 with empty triple intersection).** If H is k-uniform and T-covering with n ≥ 3k/2 + r + 1, some
pencil triple has wt ≤ 2r + 1.
*Proof.* Follow Lemma 8. In the case d ≤ k + r, take the k + r − d extra points of S outside B1 ∪ B2. There are
n − k − d/2 ≥ k + r − d of them, because d ≥ k − 1. Then B3 ⊆ S misses B1 ∩ B2. In the case d ≥ k + r, B3 ⊆ B1 + B2
already misses it. (In Lemma 8 as verified, the extra points may fall in B1 ∩ B2; this choice avoids that.)

**Theorem C1.** Let H be k-uniform and seven-free, and T = τ − 1 ≥ k/2 + 1. Then:
- (a) P(H) ≥ 4T − 3k − 5. With T = (3/4+ε)k this is about 4εk: every pencil triple is robustly far from x3 = x1 + x2.
- (b) P(H) ≤ 2r + 1.
- (c) Hence 6T ≤ 2n + k + 6, i.e. **τ ≤ (2n + k)/6 + 2 = (3/4 + δ/3)k + 2**. So τ > (3/4+ε)k + 2 forces δ > 3ε.
  - No restriction on N is needed, since P1 builds a Fano-type seven directly.
  - This beats Theorem 3's τ ≤ 3n/7 + 3 for every n > 7k/4 + O(1).
  - It agrees with Theorem NC applied to W = V with d = r, which gives the same threshold δ < 3ε.
  - Sanity checks: K_13^(8) (τ = 6 ≤ 7.7), K_10^(6) (5 ≤ 6.3), FKW m = 3 (10 ≤ 11.3).
- (d) *Hole form of (a).* For members x1, x2 with D = x1 + x2 and d = |D| < k + ρ0, where ρ0 = 4T − 3k − 5: every set
  D ∪ E with E ⊆ V∖(x1∪x2) and |E| < (ρ0 + k − d)/2 is a hole. A member x3 inside it would have wt(x1+x2+x3) =
  d − k + 2|x3∖D| < ρ0. Since holes have size ≤ k + r − 1, pairwise distances avoid the band (k + 2r − ρ0, k + ρ0) up
  to O(1). The band is non-empty only for δ < 5ε. Iterating the band against Lemma 8's pair construction gives nothing
  beyond (c) [proved by hand; no further gain].

## 5. Two-block families: an exact test bed
Let V = X ⊔ Y with |X| = a, |Y| = b, and H_J = {k-sets B : |B ∩ X| ∈ J} for any J ⊆ [0, k]. These include complete
families, FKW and H1's core, and every "mod-q" or "junk-layer" variant. All checks are exact on orbits:
- τ = n − (largest hole profile), where a hole profile (x, y) has J ∩ [k − y, x] = ∅;
- a seven exists iff integers x_p, y_p give, for every line, J ∩ [k − Y_ℓ, X_ℓ] ≠ ∅ (HiGHS ILP);
- the best half-space fraction is exact over all functionals (Krawtchouk sums).
Sanity: FKW m = 2, 3 at 7m + 1 have no seven and at 7m + 2 have one (explicit and verified); K_13^(8) has none and
K_14^(8) has one. All four agree with Task 0.

**Theorem C2.** If 3k/2 ≤ n < 9k/4 and τ(H_J) ≥ 3k/4 + 3, then H_J has a Fano-type good seven.
*Proof.*
- If some j ∈ J lies in [k − 2b/3, 2a/3], take three j-subsets of X (and (k−j)-subsets of Y) with empty triple
  intersection and at most one once-covered point each. This needs ⌈3j/2⌉ ≤ a and ⌈3(k−j)/2⌉ ≤ b. Then w ≤ 2 ≤
  4T − 3k − 6, and P1 applies.
- Otherwise J has a gap containing that window. Then there is a hole of size ≥ ⌊2a/3⌋ + ⌊2b/3⌋, so τ ≤ n/3 + 2 <
  3k/4 + 3.
Test (`test_c2b.py`): 600 random instances with k = 8..40 and τ ≥ 3k/4 + 3. All of them fell in the first case, and
all 600 explicit sevens were verified; 80 of them were also cross-checked by ILP [computed exact].

**Exhaustive search below the threshold** (`search2.py`, every J and every split a ≤ b) [computed exact]:

|---|---|---|---|---|---|
| 8 | 14 | 1.750 | 6 | 6 | (6, {0,2,3,5}): 0.776 |
| 10 | 18 | 1.800 | 8 | 7.5 | (7, {0,2,3,5,7}): 0.860; FKW-type (8, odd): 1.000 |

- At τ = 3k/4 + O(1), "parity coset plus a junk layer" survives with 14–22% of the members off the coset. In these
  examples 4T − 3k ≤ 0, so P1 has no force.
- This matches Task 4: every seven-free example has 4T − 3k ≤ 0.
- So the o(|H|) in C is a genuinely asymptotic statement. It cannot be checked at small k, and a finite-k counterexample
  to the asymptotic target is impossible unless (G) itself fails there.

## 6. Best statement and the exact remaining gap
**Proved (C1 + C0 + CL).** A seven-free k-uniform family with τ > (3/4+ε)k + 2 satisfies all of the following:
- (i) n ≥ (7/4 + 3ε)k;
- (ii) every pencil triple has wt(x1+x2+x3) ≥ 4εk − 5 (robust Schur-freeness);
- (iii) its holes block every Fano plane. In particular, fix class sizes and colour uniformly at random; each R_ℓ is
  then a uniform set of its size w_ℓ, so Σ_ℓ h(w_ℓ) ≥ 1, where h(w) is the hole density in layer w. For 7 | n this
  gives h(4n/7) ≥ 1/7;
- (iv) every would-be seven with pencil slack S is S/2-close to a linear Fano plane.

**Gap INV-P [open].** Let H be k-uniform and T-covering on n = (7/4+δ)k points, with 3ε ≤ δ < 1/12 (N < 11/6), thin,
with no (k+d)-covered W of size ≥ (7/4−ε)k + 2d + 3, and with P(H) ≥ 4εk − O(1). Show that all but o(|H|) members
lie in one coset a + C with every pencil sum in a + C. Then ρ(a + C) ≥ P ≈ 4εk, which is the input for B, including
B's open robustness to the o(|H|) exceptional members.
- The "no covered W" hypothesis is **[conditional on NC]**: it is free only if Theorem NC holds, and NC is not yet
  verified. INV-P *without* that hypothesis must instead allow a near-complete conclusion.
- Proving C reduces to INV-P **[conditional on NC]**: C1(a) gives P(H) ≥ 4εk unconditionally, but dropping the
  near-complete branch uses NC.
- Nothing in §§1–5 uses NC. C1, C2, P1, Lemma 8′, CL and C0 are unconditional. The agreement of C1(c) with NC is only
  a cross-check: if NC fails, C1(c) still stands.
- INV-P is a sparse, shell-restricted analogue of the stability theorem for sum-free sets in F₂^m. Davydov–Tombak: a
  sum-free set of density > 5/16 lies in a hyperplane complement.
- The natural Fourier/regularity output is weaker: H ⊆ ∪_{v∈S}(v + C) with S ⊆ F₂^V/C sum-free, and every class of
  S + S + S of minimum weight ≥ 4εk.
  - If S has density > 5/16 in F₂^V/C, Davydov–Tombak makes it a single coset, and we are done.
  - **The precise obstruction to check is a non-linear sum-free S of density ≤ 5/16 with heavy S+S+S classes.** This
    needs codimension Θ(k), i.e. B's many-class regime [heuristic].
  - No such covering family is known. The stored seven-free families are all ρ = 2 cosets up to ≤ 12 members
    (Task 4).
- The density input has to come from covering, not from counting. H can be exponentially sparse in the k-slice, and
  random covering designs have about e^{2k} perfect pencils [heuristic count], so they are excluded by (ii). The usable
  forms are C1(d), the hole form, and C0, holes blocking Fano planes.

**Sub-question Pencil-D [open, heuristic].** Does every k-uniform T-covering family have a pencil triple of weight
≤ r + O(1)? This would be the family analogue of Theorem D's c* = 1.
- If true, C1 improves to δ ≥ 5ε. It holds trivially for two-block families (P ≤ 2) and is consistent with Task 4
  (FKW: 2 = r + 1; tgw k = 13: 1 ≤ r + 1).
- Lemma 8′ gives 2r + 1, and the loss sits exactly in the d ≤ k + r branch. Closing it is a cleaner first target than
  INV-P.

**What does not work** [dead]:
- BLR gluing of local affine 3-spaces from the 7-term condition (§3).
- Arguments with O(1) slack (§5 junk-layer examples).
- Near-sevens are not abundant in any usable sense: seven-free means *every* colouring has a hole line, so near-sevens
  exist only as 6-line configurations. Their 6-line stability (§2) is again 7-term-type.
