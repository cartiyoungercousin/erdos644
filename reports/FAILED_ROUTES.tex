\section*{Setting}
\textbf{Units.} We work in units of $k$, with $t=T/k=\tfrac34+\varepsilon$ ($\varepsilon$ small), $N=|V|/k$, co-edge mass
$c=N-1$, free mass $\omega=N-1-t$ and $\delta=N-\tfrac74$.

\textbf{The open statement (CP).} For $5t-2<N<3-t$, every \emph{$T$-covering} family of co-edges contains seven members
covering all pairs of $V$. $T$-covering means that every $T$-subset of $V$ lies in some co-edge.

\textbf{What suffices} \lvl{VERIFIED}. CP follows from $(\Sigma)$: the family contains one of
\begin{itemize}
\item a Q$'$ quadruple;
\item a pencil triple (union $V$, triple intersection $\ge N-2t$);
\item a Theorem-T triangle.
\end{itemize}

\textbf{What a counterexample would have to be} \lvl{VERIFIED}. It is not a bounded blow-up (Theorems S, S$^+$). It is
not a fixed-order rule. It is not a rule choosing among orders by a window of at most $T-k/2$ points (Theorem W). It
does not have kernel density above $2/3$ (Theorem H). It is not a random or 6-wise independent selector (Theorem R).
What remains are deterministic, strongly anti-correlated families.

Status tags below: \lvl{VERIFIED} means independently checked; \lvl{HAND} means a hand proof not yet independently
checked. Section numbers refer to \texttt{notes/CORE.md}.

\section*{Routes that fail}
\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
\item \textbf{Bounded-request games} (Parts V--VII). \lvl{HAND/FLOAT}
 \begin{itemize}
 \item At depth 2 and 3, the requester saves nothing over the baseline cost $2\omega$ and $3\omega$.
 \item A ``W-dumper'' adversary beats every fixed-labelling strategy above $N=5t-2$.
 \item A history-dependent adversary is not stronger than a family at full depth. So only depth limits the game, and
 small depth does not suffice.
 \end{itemize}
\item \textbf{Kernel lemma} (\S34--35). \lvl{HAND} Dumps landing in a common core give \emph{need} equal to the baseline
whatever their overlap. No common core is forced.
\item \textbf{Exact regularity or symmetrisation} (\S39). \lvl{HAND} The upper profile closure keeps $T$-covering but
always has a good seven, by Theorem S. The lower kernel keeps ``no good seven'' but loses covering. So the property that
must be transported is exactly the one symmetrisation destroys.
\item \textbf{Raising the S$^+$ cell bound to $c(N)k$} (\S45). \lvl{HAND} The pool family has slack exactly
$4\varepsilon k$ in every good seven. SPOIL-type rules refine their cells at every reply, so they pass any $ck$ bound.
\item \textbf{Junta approximation in measure} (Dinur--Friedgut, Keller--Lifshitz; \S50--53). \lvl{HAND} The families
have density $e^{-\gamma k}$, so $o(1)$-measure errors are vacuous. Keller--Lifshitz needs $k<n/C$.
\item \textbf{Spread and sunflower lemmas} (ALWZ, FKNP; \S50--53). \lvl{HAND} A family of $c$-sets on $n$ points is at
most $n/c<2.3$-spread, while the lemmas need spreadness above 32.
\item \textbf{Kupavskii--Zakharov decomposition} (\S54). \lvl{HAND} It splits requests into classes with linear-size
heads plus a remainder. The structured part is exactly the open hash-selector problem, so this restates the problem
rather than reducing it.
\item \textbf{Fractional transversal, then rounding} (\S80--84). \lvl{HAND} For $(7,2)$-families, $\tau^*\le
(35k)^{1/3}$, so the fractional version cannot see the constant $3/4$. In the window, rounding is CP itself. The
$\varepsilon$-net step of Alon--Kleitman type arguments cannot reach $3/4$.
\item \textbf{Fractional pair-cover (clique-cover) LP} (\S115--119). \lvl{HAND+EXACT} We have
$(N/c)^2\le\rho^*\le(N/t)^2$. Pool variants with $\rho^*\approx 5.44$ need $\rho\ge 8$ sets, at the same $\rho^*$ as
families with $\rho=7$. So no statement of the form ``$\rho^*$ small implies $\rho\le 7$'' can hold.
\item \textbf{Hypergraph containers and supersaturation} (\S85--89). \lvl{HAND}
 \begin{itemize}
 \item The codegree condition at $j=2$ needs $\log|X|\ge(r+1)\gamma$. It fails everywhere except a thin strip.
 \item Every container of a counterexample is itself $T$-covering. So the supersaturation statement needed already
 implies CP.
 \end{itemize}
\item \textbf{Flag algebras and SDP} (\S75--79). \lvl{HAND}
 \begin{itemize}
 \item The Cauchy--Schwarz constraints are automatic.
 \item CP is not a density inequality: good sevens have vanishing density even when they exist.
 \item ``No good seven'' does not pass to the limit.
 \end{itemize}
\item \textbf{Density and forbidden patterns above the bottom strip} (\S95--99). \lvl{VERIFIED, Theorem 96.1}
 \begin{itemize}
 \item The $c$-sets that avoid one point and contain a fixed $Y$ form a dense family (rate $\le 0.2\gamma$) with no
 static certificate.
 \item So density alone cannot force a certificate. This method closed the bottom strip but stops there.
 \end{itemize}
\item \textbf{Adaptive density via links, traces and exclusions} (\S100--104). \lvl{HAND}
 \begin{itemize}
 \item A link through $s$ points keeps $\omega$ but lowers $\varepsilon$ to $\varepsilon-s$. That moves away from every
 closed region, and for $s>\varepsilon$ the reduced statement is false.
 \item Traces lower $\omega$ only on paper, and exclusions cannot be forced.
 \item \emph{Theorem 102.1}: a static certificate's budget $(q-3)\delta+(7-q)\varepsilon$ depends only on $(N,t,q)$.
 \end{itemize}
\item \textbf{Fano-ratio links} (external suggestion). \lvl{HAND} A core of size $(N-\tfrac74)k$ gives links on
$\tfrac74k$ points with blocks of $\tfrac34k$ points (ratio $3/7$). But their strength is $t'=t-\delta<\tfrac34$, which
is below threshold, so a single-link lemma is false. Using all links together is CP again.
\item \textbf{Entropy methods} (Gilmer; Alweiss--Huang--Sellke; Chase--Lovett; Sawin; \S70--74). \lvl{HAND}
 \begin{itemize}
 \item An explicit family with no good seven is larger than the smallest $T$-covering family, so the size form fails.
 \item Seven independent members leave 7.5--24\% of the pair mass uncovered.
 \item Every certificate needs cyclic constraints among at least three dumps, and entropy only controls acyclic orders.
 \item The witness-pair version is just a union bound over pairs.
 \end{itemize}
\item \textbf{Covering-design stability, anti-Pasch analogies, code constructions} (\S105--109). \lvl{HAND/FLOAT}
 \begin{itemize}
 \item Pool families are inclusion-minimal yet far above the Schönheim bound, so size-stability is the wrong axis.
 \item Random designs are supercritical for $(\Sigma)$-shapes.
 \item Code families would need more redundancy than covering allows.
 \end{itemize}
\item \textbf{Steps for hash-like selectors} (\S48, \S55--59). \lvl{HAND+EXACT} The $2/3$ averaging bound cannot be
improved over one kernel (Kleitman). Pencil-free two-class selectors exist at $k=8$, so the ``two-ground'' step is
false. ``Three classes always escape a pencil'' is also false.
\end{enumerate}

\section*{Lessons: what a successful argument must do}
\begin{enumerate}[leftmargin=*]
\item Use the \textbf{full $T$-covering hypothesis}, not only density or link density (routes 5, 6, 12, 13, 16).
\item Use \textbf{adaptivity} in an essential way, since no fixed plan or request distribution suffices (routes 1, 9,
13), and handle cyclic dependencies among replies (route 15).
\item Handle the \textbf{near-pool families} with an adaptive pencil finish. These sit exactly at the static budget
(Theorem 102.1), so this is the stability problem of \S33(4).
\item Defeat \textbf{deterministic anti-correlated} selectors. The model case is the two-class reversed-order family at
$k=8$: it has 0 pencils, against $1.3\times10^5$ for a random family of the same size, and no $(\Sigma)$-shape at $\varepsilon=0$.
\end{enumerate}
